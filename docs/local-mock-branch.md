# 本地模拟分支

分支：`codex/local-mock-no-auth`。

运行 `npm run dev`，直接进入护士站，无需账号、角色确认、后台地址或 `config.json`。`npm run build` 的产物具有相同行为。

此分支固定使用 `src/mock` 的医院、病房、床位、患者、模板、呼叫、输液报警、响应时效和巡视数据；环境、呼叫和设备状态使用本地模拟器。`VITE_DATA_SOURCE` 和实时推送地址不会启用远端数据。处理记录保存在浏览器本地，不向后台同步。

开发服务器和预览服务器均不设置业务代理，后台 HTTP 和数据库请求入口已禁用。模型、视频和图片仍需从本地部署包加载，属于静态资源。终端模板图片使用内嵌模拟图。

工作区原有未提交改动随分支切换保留；本次未创建提交或推送。
