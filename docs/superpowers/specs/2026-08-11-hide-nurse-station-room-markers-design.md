# 护士站隐藏病房态势标记设计

## 目标

护士站场景不再显示“重点病房”悬浮标记，避免面板遮挡 3D 模型。

## 调整范围

- 移除 `NurseStationVisualScene` 中重点病房标记的渲染入口。
- 清理仅供这些标记使用的状态计算、文案映射、定位配置和样式。
- 保留护士站 3D 场景、左下角病区信息、进入病房走廊按钮和面板总开关原有行为。
- 保留病房汇总数据及选择标记的核心逻辑，避免影响其他页面或后续复用。

## 验收标准

- 进入护士站后不出现病房名称、状态和床位数量悬浮标记。
- 左下角病区信息与“进入病房走廊”按钮仍正常显示和操作。
- 项目类型检查和生产构建通过。

## 验证方式

项目未配置组件测试框架，因此先用静态源码检查约束组件不再包含标记入口，再执行完整构建；最后启动页面进行视觉检查。
