# 病房面板显示开关设计

## 目标

将护士站已有的“显示/隐藏面板”能力扩展到病房和病房内视图，提供一致的沉浸式查看体验，同时保留必要的导航与床位交互。

## 交互范围

- 护士站、病房、病房内共享一个页面级面板可见状态，进入应用时默认显示。
- 切换场景时保留当前显示状态，不因进入病房或返回走廊而重置。
- 隐藏状态覆盖页面信息层：左右信息栏、房间导航、病房图例、环境告警、定位告警及装饰边框。
- 顶部系统标题、底部主导航、3D 场景、床位浮签、设备标签、床位点击和相机交互始终保留。
- 按钮提供准确的 `aria-label` 和 `aria-pressed`，图标与文案同时表达状态。

## 布局与视觉

- 开关固定在主场景右下角、底部导航上方，避免与底部导航和病房内部提示条重叠。
- 使用项目现有深色半透明 HUD 风格：克制的青色边框、柔和阴影、8px 以内圆角和高对比文字。
- 使用眼睛/隐藏眼睛语义图标；展开态显示“隐藏面板”，收起态显示“显示面板”。
- 桌面端使用图标加文字；窄屏保持紧凑尺寸并考虑底部安全区，文字不得溢出。
- 隐藏面板后主场景扩展到可用空间，不留下侧栏空白。

## 实现边界

- 在 `App.vue` 将现有护士站专属状态重命名为通用页面面板状态。
- 使用单一计算条件驱动边框、左右侧栏、病房导航、图例、告警和护士站场景覆盖层，避免各视图出现不同步状态。
- `NurseStationVisualScene` 继续通过现有 `overlaysVisible` 属性接收同一状态。
- 不修改 Three.js 场景业务逻辑、病房模型、床头屏 JSON 解析或数据接口。

## 验证

- 增加边界测试，覆盖三类视图都渲染开关、通用状态控制目标面板，以及导航和场景不被隐藏。
- 运行类型检查和生产构建。
- 在桌面与移动端分别视觉检查病房走廊和病房内：按钮位于右下角且不与底部导航重叠；切换后侧栏、导航、图例和告警正确隐藏/恢复。
