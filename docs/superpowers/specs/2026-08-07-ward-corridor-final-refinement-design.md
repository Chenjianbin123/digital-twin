# 病房走廊七项精修设计

## 目标

在已确认的 4 米宽智慧病房走廊概念模型上完成七项真实医院环境精修，使画面更有层次，同时为后续数字孪生交互保留清晰的对象边界。

## 精修内容

1. 候诊椅改为更深的灰绿色医用皮革，增加克制的坐垫与靠背接缝。
2. 三组安全提示牌缩小约 15%，统一白色底板、深色中文和窄色标，统一安装高度。
3. 十个病房门增加 `301` 至 `310` 房号，房号位于门框上方并保持独立对象。
4. 地面增加低对比度医用地胶拼接缝，不使用强反射或复杂花纹。
5. 降低尽端窗户自发光和补光强度，增加磨砂横向遮阳片，保留窗框层次。
6. 吊顶在现有灯具、风口和喷淋基础上，克制增加烟感、半球摄像机和检修口。
7. Blender 中建立 `WardDoors`、`DoorScreens`、`RoomNumbers`、`Seating`、`SafetySigns`、`CeilingEquipment` 六个集合，并为交互对象写入 `interaction_role` 自定义属性。

## 约束

- 走廊中部净通道不低于约 2.4 米。
- 不显示护士站，不开启病房门。
- 门口屏继续作为独立材质面，保留项目现有接口模板解析方式。
- 可见文字仅使用中文和数字。
- 本次只更新概念 PNG、Blender 源文件和可复现生成脚本，不替换项目正式 GLB。

## 验收

- 1600×900 效果图中可辨认深灰绿色座椅、房号、地胶接缝和吊顶设备。
- 尽端窗户不再大面积过曝，窗框和遮阳片可见。
- 三组安全提示牌尺寸和安装高度一致。
- Blender 文件包含六个目标集合，门、屏幕、房号、座椅和标识可独立选择。
- 脚本内场景验收通过，PNG 与 `.blend` 同步更新。
