# 登录页面精简设计

## 目标

精简数字孪生登录门禁的信息层级，删除无业务价值的英文品牌和状态提示，让用户进入页面后直接看到系统名称与登录表单。

## 页面内容

- 将登录区大标题“值班人员登录”改为“智慧病房数字孪生平台”。
- 登录按钮文案改为“登录”。
- 删除顶部 `DNK MEDICAL`、`SMART WARD COMMAND` 和十字标记。
- 删除 `STAFF ACCESS`、`LIVE WARD SYSTEM` 和 `ROLE CONFIRMATION`。
- 删除“使用 SWP 平台账号验证身份”。
- 删除底部“智慧病房服务”和“安全连接”。
- 保留平台账号、登录密码、密码显示/隐藏、提交中状态和错误提示。
- 登录界面的动态文案全部使用中文，不展示英文标题或辅助说明。

## 布局

- 保留护士站实景背景和右侧深色登录区域。
- 背景场景图片内的模型标识保持不变，不将其作为登录界面文案处理。
- 登录表单整体向上收拢，缩短无内容区域。
- 标题、输入框和按钮保持现有对齐关系与响应式宽度。
- 移动端继续使用全宽登录区，确保标题和表单均在首屏内。

## 功能边界

- 不修改 SWP 登录接口、MD5 密码摘要、角色选择和 Token 生命周期。
- 角色确认步骤继续显示用户姓名、角色列表、确认按钮和切换账号按钮。
- 登录错误和会话过期信息继续保留，因为它们属于必要反馈。

## 验证

- 边界测试确认废弃文案已删除且新标题、按钮文案存在。
- TypeScript 与生产构建通过。
- 浏览器检查桌面和移动端无多余空白、遮挡或文字溢出。
