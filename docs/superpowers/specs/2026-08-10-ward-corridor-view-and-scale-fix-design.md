# 病房走廊视角与空间尺度修复设计

## 目标

修复病房走廊 GLB 初始化时从建筑外侧俯视的问题，恢复接口模板驱动的门口屏可见效果，并让走廊更宽、更高。

## 已确认设计

- 走廊净宽从 4.0m 调整为 5.2m。
- 层高从 3.2m 调整为 3.8m。
- 初始化相机位于走廊入口内部，使用接近人眼的高度沿走廊中心轴观察。
- 动态门口屏显示面移到屏幕外壳朝向走廊的一侧，保留现有接口模板解析和回退纹理逻辑。
- 门、门口屏、房号牌、扶手、安全提示和座椅随两侧墙体一起外移，保持纵向门位间距不变。
- OrbitControls 保留旋转、缩放和平移，并限制相机初始距离，避免初始化再次落到屋顶外侧。

## 验证标准

- 切换到病房后首帧位于走廊内部，不看到大面积屋顶或外墙。
- 左右两侧至少一组门口屏在初始视角可见，旋转后其余门口屏可见。
- 门口屏显示 301–310 对应模板内容；无数据门位仍显示“空床”。
- Blender GLB 包围盒宽度约 5.4m，高度约 3.9m。
- TypeScript 构建与门位映射测试通过，浏览器控制台无 GLB/纹理错误。

## 墙面挂件修复补充

- 门牌、提示语、扶手和座椅使用同一个 `WALL_OFFSET` 计算，随走廊扩宽同步外移。
- 门牌和提示语必须贴近对应墙体内侧表面，间距控制在 0.02m 至 0.12m。
- Blender 构建阶段直接断言挂件到墙面的距离，防止再次出现悬空。
