# Nurse Station Model Scale Adjustment Design

## Goal

将护士站高精度模型在现有视角中整体缩小 10%，增加模型四周留白，同时保持当前构图、交互和动态屏幕行为不变。

## Design

前端继续使用现有 `fitNurseStationModel()` 包围盒适配逻辑，仅将 `NURSE_STATION_MODEL_MAX_SIZE` 从：

```ts
new THREE.Vector3(10.8, 2.95, 5.85)
```

调整为原值的 90%：

```ts
new THREE.Vector3(9.72, 2.655, 5.265)
```

三个轴同步缩放，避免改变模型比例。适配完成后仍沿用现有居中和落地逻辑，因此护士台不会悬空或横向偏移。

## Scope

- 只修改前端模型尺寸上限和对应边界测试。
- 不修改或重新导出高精度 GLB。
- 不修改摄像机、OrbitControls、动态屏幕名称或纹理挂载逻辑。
- 不修改加载失败时的程序化回退。

## Verification

- 先增加锁定新尺寸上限的失败边界测试，再修改实现使其通过。
- 运行护士站场景边界测试、渲染输出边界测试和生产构建。
- 在桌面 `1440x900` 和移动端 `390x844` 下重新截图，确认模型整体更小、仍居中且不与界面控件重叠。

## Success Criteria

- 模型显示尺寸相对当前版本缩小 10%。
- 护士台、门组、导视牌和动态屏幕保持可见。
- “进入病房走廊”按钮和底部导航保持可用。
- 浏览器控制台没有模型加载或动态屏幕挂载错误。
