# 高精度护士站混合渲染设计

## 目标

仅重做数字孪生系统的护士站首屏，使固定主视角下的空间比例、构图、材质、灯光和第一眼观感接近用户提供的参考图。保留真实病区数据、病房状态浮标、病区切换、刷新记忆、电视播放和进入病房走廊功能。

本设计替代 `2026-07-27-nurse-station-visual-scene-design.md` 中“全部使用浏览器实时 GLB 渲染护士站”的交付方式。病房走廊、病房内部、后端接口、数据库和权限模型不在修改范围内。

## 技术路线

采用“Blender Cycles 高质量预渲染背景 + 浏览器动态业务图层”的固定视角方案。

- Blender 负责建筑、护士台、设备外壳、柜体、灯光、材质、反射和阴影。
- 网页负责中央电视、电子时钟、病房浮标、病区名称和设备状态。
- 背景不包含患者信息、固定时间或真实业务状态，避免业务数据被烘焙到图片中。
- 护士站不提供自由旋转、缩放和漫游；病房走廊与病房内部继续沿用当前实时 3D 场景。

该路线优先保证固定视角的视觉精度和浏览器性能。现有实时护士站模型作为背景资源加载失败时的回退，不作为本次主要视觉交付。

## 视觉构图

画面按参考图建立正面、对称、稳定的医院护士站构图：

- 前景为大尺寸白色弧形护士台，包含圆角台面、内侧工作区、四台显示器、键盘、电话、打印设备和座椅。
- 中景为中央信息墙、独立大屏、白色储物柜、文件夹、绿植和右侧红色电子时钟。
- 左右两侧形成可辨识的病区走廊，包含木色病房门、观察窗、蓝色扶手、踢脚线和导视细节。
- 顶部使用模块化吊顶、矩形灯盘和均匀冷白照明；地面保留柔和反射和空间纵深。
- 主体保持完整可见，并为顶部病房浮标、底部导航和右侧操作入口预留不遮挡关键设备的区域。

场景为原创重建，不复制参考图中的品牌、患者数据或具体业务界面。

## Blender 资产与渲染

在独立的高精度 Blender 场景中重建护士站，保留可重复生成和渲染的源文件。

- 近景硬表面使用真实倒角、平滑法线和合理厚度，消除当前低模场景的锐利边缘与块状感。
- 使用 PBR 材质表现白色人造石、哑光墙漆、浅蓝耐磨地面、木门、玻璃、金属和屏幕外壳。
- 使用面光源、环境光和间接照明形成柔和阴影、接触阴影与自然反射，避免全局发白。
- 使用 Cycles 输出不低于 `3840x2160` 的主背景，并生成网页展示尺寸的优化版本。
- 渲染输出使用稳定色彩管理，避免高光过曝；景深保持轻微，不模糊中央设备和两侧病房门。
- 中央电视、电子时钟和需要动态覆盖的显示区域渲染为空白或中性暗色表面，并记录其归一化矩形坐标。

## 动态合成层

`NurseStationVisualScene.vue` 作为混合场景容器，背景和动态内容共享同一个固定比例坐标系。

- 背景层显示 Blender 渲染图，使用受约束的 `object-fit` 规则保持构图。
- 中央电视层继续播放现有宣教视频，使用屏幕坐标裁切并匹配圆角、亮度和轻微反射。
- 电子时钟层显示浏览器实时本地时间，不在背景中写死时间。
- 病房浮标继续读取现有 `area.rooms` 与 `roomSummaries`，按归一化锚点定位。
- 点击浮标继续进入对应病房；“进入病房走廊”继续调用现有场景切换逻辑。
- 顶部病区名称和切换入口继续使用现有真实接口与病区记忆状态。

背景尺寸变化时，动态层通过统一的画布缩放与偏移参数计算位置，禁止各图层各自按视口定位，以避免视频和浮标错位。

## 响应式行为

- 桌面端以完整参考构图为主，护士台、中央大屏和左右走廊均可见。
- 宽屏端使用受控留白或轻微裁切，不横向拉伸背景。
- 移动端优先保留护士台与中央大屏，可裁切两侧走廊；浮标数量沿用当前移动端规则。
- 动态视频、时钟和浮标必须跟随背景画布同步缩放和偏移。
- 底部导航、右侧入口和病区切换控件不得遮挡中央大屏、护士站标牌或主要浮标。
- 遵循“减少动态效果”设置，禁用非必要的渐入和视差动画。

## 加载与错误处理

- 高精度背景先显示轻量占位，再渐显正式资源，避免黑屏和布局跳动。
- 背景加载失败时回退到现有实时护士站 GLB，并保留全部交互。
- 视频自动播放被阻止或资源失败时，中央屏幕显示当前病区概览看板。
- 真实接口失败时沿用当前错误状态，不使用本地模拟数据伪装成功。
- 单个动态图层失败不得影响病区切换、进入走廊或其他护士站交互。

## 性能约束

- 网页背景提供现代格式和兼容格式，按实际显示尺寸选择资源，避免所有设备下载原始 4K 文件。
- 首屏高精度背景、视频与现有场景资源分开加载；进入护士站时只加载所需资源。
- 离开护士站后暂停视频并释放不再使用的媒体资源。
- 不新增重量级实时后处理依赖，因为写实灯光与材质已包含在预渲染背景中。

## 验收标准

- 桌面主视角在构图、空间比例、护士台造型、两侧走廊、中央信息墙、吊顶灯光和蓝白材质关系上明显接近参考图。
- 场景不再呈现当前低模、全局发白、灯具重复密集和视角偏斜的问题。
- 中央视频在正确屏幕区域内播放，没有溢出、漂移或遮挡屏幕边框。
- 病房浮标读取真实病区数据，切换病区后内容同步更新，刷新页面后保持已选病区。
- 点击浮标、进入病房走廊、返回护士站和底部导航行为保持现状。
- 病房走廊和病房内部的模型、相机与交互没有变化。
- 桌面与移动视口截图中无黑屏、拉伸、明显错位、文字重叠或关键控件遮挡。
- 运行护士站边界测试、病区切换相关测试和生产构建。

## 明确不做

- 不提供护士站自由漫游、自由旋转或缩放。
- 不把患者姓名、病区统计、时间或设备状态烘焙进背景。
- 不重做病房走廊和病房内部。
- 不修改后端接口、数据库、登录或权限模型。
- 不新增人物模型、人物动画或新的业务流程。
- 不承诺任意视角下的照片级实时 3D；高精度验收仅针对确认的固定主视角。
