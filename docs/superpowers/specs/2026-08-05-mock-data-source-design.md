# 模拟数据源切换设计

## 目标

开发环境使用项目现有的本地模拟数据运行，不再依赖智慧病房设备端后端。

## 设计

- 将 `.env.development` 中的 `VITE_DATA_SOURCE` 从 `remote` 切换为 `mock`。
- 复用 `src/mock`、`src/api/door-device.ts` 和现有模拟推送服务，不新增接口层或依赖。
- 启动阶段在非远程模式直接调用现有 `store.loadArea()`；远程模式继续使用病区选择和恢复流程。
- 保留远程接口地址和参数，便于后续切回 `remote`，但 Mock 模式不调用它们。
- 重启 Vite 开发服务器，使环境变量重新加载。

## 验收

- 页面可以在无后端服务的情况下加载护士站及病房数据。
- 页面数据源标识显示“模拟数据”。
- 模拟推送入口可见。
- 类型检查和生产构建通过。

## 非目标

- 不修改现有模拟数据内容。
- 不搭建 HTTP Mock Server。
- 不修改远程接口和数据库适配逻辑。
