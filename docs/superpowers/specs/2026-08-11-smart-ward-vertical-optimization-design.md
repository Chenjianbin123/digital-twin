# Smart Ward Vertical Optimization Design

## Goal

在保留智慧病房当前平面布局的前提下，将完整场景沿 Blender Z 轴拉高 12%，并修正可移动设备悬空问题。

## Current State

- 源文件为 `smart_ward_scene_highres.blend`，场景地面完成面位于 `Z=0`。
- 房间当前净高约 `3.5 m`，场景包含 265 个对象。
- 两组床旁监护仪脚轮最低点均为 `Z=0.435 m`，存在明显悬空。
- 共享护理车主体最低点为 `Z=0.19 m`，同样未接触地面。

## Design

以世界坐标地面 `Z=0` 为固定基准，通过场景根节点对所有可见场景对象应用 `1.12` 的世界 Z 轴倍率：

- 新增空对象 `SmartWardVerticalScale`，将网格、曲线、文字和灯光挂到该节点下，并设置 `scale.z = 1.12`。
- 使用根节点缩放保证旋转过的脚轮、线缆和灯光仍沿世界竖直方向统一拉高，不发生局部轴误缩放。
- X/Y 位置、旋转与 X/Y 尺寸保持不变。
- 相机不挂到缩放节点；其位置和目标点单独随场景高度同比调整并重算朝向，保持当前双床主体构图。

完成全局拉高后，分别按世界坐标包围盒最低点修正两组床旁监护仪和共享护理车，使对应组最低点精确落在 `Z=0`。同组零件统一平移，避免设备内部结构错位。

修改结果另存为 `smart_ward_scene_highres_optimized.blend`，不覆盖原始文件。

## Scope

- 纵向拉高房间、病床、设备、灯光、相机和装饰物。
- 修正 `Monitor_1_*`、`Monitor_2_*` 和 `SharedCare*` 设备组的落地高度。
- 不改变平面布局、材质、灯光功率、渲染分辨率或采样设置。
- 不增加新模型、贴图、动画或外部依赖。
- 不修改原始 `.blend` 文件和生成脚本。

## Verification

- 验证优化文件可由 Blender 5.1 正常重新载入。
- 验证普通场景对象的高度和 Z 坐标相对原稿均为 1.12 倍。
- 验证两组监护仪及共享护理车的世界包围盒最低点均为 `Z=0`，允许误差 `0.001 m`。
- 使用当前主相机生成 Eevee 预览，检查设备无悬空或穿地、双床构图完整、天花与地面均有合理留白。
- 确认源文件修改时间和内容未发生变化。
