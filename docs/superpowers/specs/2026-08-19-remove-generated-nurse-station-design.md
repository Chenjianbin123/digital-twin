# 移除代码生成的备用护士站场景

## 目标

护士站阶段只显示项目中的高清 `high_fidelity_nurse_station.glb`。移除截图所示的代码生成备用场景，避免高清模型加载异常或切换过程中展示不符合预期的简化护士站。

## 方案

- 保留 `NURSE_STATION_MODEL_URL` 指向的高清 GLB，以及其模型适配、动态屏幕挂载和状态回调。
- 删除 `buildHospitalNurseStation` 在护士站初始化流程中的创建、挂载和备用场景专用引用。
- 删除备用场景的护士排班板、呼叫铃等仅用于生成场景的更新逻辑；保留业务数据更新接口，但在无备用对象时安全跳过。
- 保留护士站医院环境、相机、控制器和高清模型生命周期逻辑。
- 高清模型加载失败时继续上报 `fallback` 状态，但不再显示生成场景；页面由现有状态提示处理。

## 验证

- TypeScript 单元测试通过。
- `npm run build` 通过。
- 检查项目引用，确保没有遗留的备用场景挂载或未定义引用。

## 风险与边界

这次变更不删除高清 GLB、Blender 源文件或动态屏幕逻辑，不修改病房走廊和病房内部场景。
