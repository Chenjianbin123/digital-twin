# 护士站医院融合版效果图设计

## 目标

在不改变护士站高精度 GLB 主体、模型位置、尺寸上限和纵向比例的前提下，使护士站更自然地融入现有医院数字孪生场景，并输出桌面端与移动端效果图供确认。

## 设计方向

采用“医院融合版”，不继续增加大块顶部结构，也不把空间改成偏展厅或偏科幻的视觉风格。

### 保留项

- 使用 `high_fidelity_nurse_station.glb`。
- 模型尺寸上限保持 `8.748 × 2.3895 × 4.7385`。
- 纵向倍率保持 `Y × 1.1`。
- 保留 V3 的真实透视构图和两侧门组位置。

### 光照与空间

- 将偏冷、偏强的展示光调整为医院常见的柔和中性白光。
- 降低青蓝补光强度，保留足够的空间层次和柜台轮廓。
- 顶棚只优化灯具、墙顶过渡和阴影，不新增大面积悬浮构件。
- 地面、墙面、踢脚线采用与病区接近的浅灰、医疗绿和低饱和青色。

### 信息与使用状态

- 为护士站黑色屏幕补充床位状态、呼叫信息和排班摘要，避免大面积纯黑。
- 增加少量办公椅、文件架或工作设备，控制密度，避免遮挡主体。
- 使用医院导视语义，如护士站、安静通行和科室方向，但不堆叠装饰文字。

## 实现边界

- 本阶段只创建独立 V4 预览，不修改正式场景代码和 GLB 文件。
- 附加物使用 Three.js 程序化几何体和 Canvas 纹理，确保预览可直接运行。
- 所有新增元素放在独立组中，便于后续选择性迁移到正式场景。

## 验收标准

- 桌面与移动视口中，模型完整可见且没有不自然的顶部黑区。
- 屏幕信息清晰但不抢夺护士站主体视觉中心。
- 场景整体亮度、色温和材质观感接近现有病房场景。
- 不改变模型尺寸、纵向倍率和 GLB 内容。
- 浏览器无新增控制台错误，WebGL 画布不是空白画面。
