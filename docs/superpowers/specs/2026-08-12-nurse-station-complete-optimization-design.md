# 护士站场景完整优化设计

## 目标

在保留现有高保真护士站 GLB、接口数据结构和病房业务逻辑的前提下，完成护士站交互闭环、信息层级、指标口径、3D 构图、加载反馈、视觉样式和资源体积优化。

## 交互

- `NurseStationVisualScene` 必须转发内部 3D 场景的房间点击事件。
- 重点病房条目使用可访问按钮，明确执行“进入走廊并定位病房”。
- 移除场景和面板内重复的“进入病房走廊”按钮，保留底部场景导航及重点病房入口。
- 护士站场景加载时显示轻量进度状态，GLB 失败回退到程序化模型时显示非阻塞提示。

## 数据与信息架构

- 首屏顺序固定为：当前运行状态、优先任务、核心指标、重点病房。
- 设备健康率从设备级在线状态计算；在现有数据仅提供床头设备状态时，设备总数取床头设备与门口机，异常数取离线或低电量床头设备，口径在界面中明确为“在线设备”。
- 将“运行指数”改为“当前运行状态”，以正常、关注、紧急表达，不再显示缺少业务定义的分数。
- 运行态势、设备环境、值班医护和实时动态放入可展开的“运行详情”，降低首屏滚动压力。

## 3D 表现

- 保留 `high_fidelity_nurse_station.glb` 和程序化回退模型。
- 默认相机聚焦护士台、主屏和后墙屏，减少天花板占比；面板显隐后自动重新构图。
- 减弱页面暗色遮罩、移除鼠标视差漂移和固定 `-32px` 偏移。
- 降低玻璃和高反射材质的环境反射强度；灯光保持中性，不再强化单一蓝青色。
- 3D 大屏继续使用当前区域数据生成，刷新链路不变。

## 资源

- 使用 glTF Transform 对 GLB 执行 Meshopt、纹理 WebP 和去重压缩；只有视觉和节点契约验证通过才替换正式文件。
- 更新模型 URL 版本参数，避免浏览器命中旧缓存。

## 验证

- 边界测试覆盖事件转发、重复入口移除、状态文案、详情折叠、加载状态和版本 URL。
- 类型检查和生产构建通过。
- 浏览器在 1440x900 与移动端视口检查：无控件重叠、主屏可见、右侧首屏层级清晰、隐藏面板后场景正确铺满。
- 对正式 GLB 运行节点契约验证，并比较压缩前后文件体积。
