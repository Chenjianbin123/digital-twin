# 病房内部场景配置化

## 目标

为病房内部建立独立、类型化的配置文件，使内部 GLB 替换、模型基础尺寸、默认镜头、视角预设、响应式镜头、交互范围和模型床位适配参数可以集中修改。

## 配置文件

新增 `src/config/ward-interior-scene.ts`，配置分为：

- `model`：GLB URL、模型基础宽高深、CanvasTexture 的 `flipY`。
- `room`：代码生成房间和 GLB 建筑适配共用的房间高度。
- `camera`：FOV、裁剪面、初始位置、初始观察点、视角预设、过渡时间和窄屏视距倍率。
- `controls`：阻尼、缩放/旋转速度、极角、方位角和随房间跨度变化的最大视距。
- `appearance`：默认背景色、曝光和基础雾参数。
- `modelBedLayout`：GLB 床位原始宽度、后向偏移、水平边距、最小/最大缩放和最大床位数量。

## 代码边界

- `ward-interior-model.ts` 继续负责模型节点校验、环境适配、床位克隆和模型床位排布，从配置读取模型及排布参数。
- `ward-scene-controls.ts` 继续计算随房间尺寸变化的控制范围，从配置读取基础值。
- `camera-presets.ts` 继续提供视角查询接口，预设数值迁入配置。
- `ward-scene.ts` 从配置读取房间高度、初始镜头、渲染外观、交互速度和过渡时间。
- 病床实时状态、患者数据、床旁终端纹理、点击选床和业务告警逻辑保持原位。

## 安全约束

- 新 GLB 必须继续提供 `WardArchitecture`、`WardProps`、`BedPrototype` 及现有动态屏幕节点；节点校验逻辑不配置化、不放宽。
- 视角预设 ID 和页面现有命令保持不变，仅允许调整各预设位置、目标点和标签。
- `modelBedLayout.maxBeds` 默认保持 6，修改时必须同时验证房间布局和业务允许的床位数。
- 配置类型和契约测试必须锁定默认值及核心模块的配置消费关系。
