# 走廊按接入数据展示

建筑 GLB 保持完整；仅为当前分组中有效绑定的房间显示设备及房号牌。
未绑定门位不生成备用屏幕、占位模板或提示牌，房门仍保留。
离线不等于未绑定：离线设备仍显示模板及离线状态。

## 导航

- 无接入数据：显示空状态，保留建筑。
- 单房：简化导航，提供定位门口屏、进入病房、恢复总览；首次进入保留走廊总览，不因只有一个房间而自动拉近。仅主动定位或恢复用户已选择的房间时聚焦。
- 多房：房号导航和稳定分组；超过十个槽位分页。
- 非现场映射继续标注分组示意，不把接入数量声称为病区总房数。
- 模板失败沿用自动重试，增加手动重试入口；成功后清除模板失败提示。
