# 新模型/模板导入备注

替换护士站、病房走廊或门口屏模型前，先按下面清单检查。

## 1. 文件格式与加载

- 确认文件是标准 `.glb` / `.gltf`。
- 如果使用 `KHR_draco_mesh_compression`，代码必须配置 `DRACOLoader`，解码目录为 `/draco/`。
- 如果使用 WebP 纹理，确认浏览器和部署环境支持 `EXT_texture_webp`。
- 不直接覆盖旧模型，先使用新文件名和 URL 查询参数，避免浏览器缓存。

## 2. Blender 命名规范

走廊屏：

```text
走廊屏1
走廊屏2
走廊屏1_屏幕
走廊屏2_屏幕
```

门口屏：

```text
门口机1
门口机2
...
门口机10
门口机1_屏幕
```

推荐屏幕材质单独命名：

```text
走廊屏内
门口机内
门口机周
```

父节点负责编号，子 Mesh 负责实际可见屏幕面。

## 3. 屏幕材质与几何

- 屏幕面必须是独立 Mesh 或独立 geometry group。
- 屏幕面材质不要和外壳、背板共用。
- 多材质模型必须保证屏幕材质能通过 `materialIndex` 找到。
- 屏幕面应有完整 UV，覆盖范围尽量为 `0～1`。
- 走廊横屏默认使用模型 Y/Z 方向；门口竖屏默认使用 9:16 比例。

## 4. 代码识别规则

- 优先按父节点名称识别。
- 父节点下只选择一个真正的屏幕 Mesh。
- 优先选择材质名包含“走廊屏内”或“门口机内”的 Mesh。
- 不能把所有子 Mesh 平铺后直接取前两个。
- 不要仅按材质全局搜索，避免把走廊屏识别成门口屏。

## 5. 显示层处理

- 如果屏幕被模型外壳遮挡，复制屏幕 geometry group 创建顶层显示层。
- 动态模板层通常设置：

```ts
renderOrder = 10000;
depthTest = false;
depthWrite = false;
```

- 斜视角出现模糊时，提高 Canvas 分辨率并配置纹理过滤、各向异性采样。
- 出现镜像或倒置时，检查 UV 的 U/V 方向和 `texture.flipY`，不要先旋转整个模型。

## 6. 数据刷新

- 模型加载完成后先显示默认模板。
- 病区接口返回后重新生成模板。
- 切换病区后重新刷新模板。
- 时间屏至少每秒刷新一次。

## 7. 导入后排查顺序

1. 浏览器 Network 确认模型请求成功。
2. 控制台确认没有 Draco/纹理解析错误。
3. 打印父节点、子 Mesh、材质名和 `materialIndex`。
4. 确认实际绑定的屏幕数量。
5. 确认 geometry group 是否为屏幕面。
6. 确认 UV 是否完整、方向是否正确。
7. 确认动态层是否被外壳遮挡。
8. 确认接口数据返回后是否触发刷新。
